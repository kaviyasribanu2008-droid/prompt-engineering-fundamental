
# Prompt Engineering Fundamentals

## Prompt Comparison
- **Initial Prompt:** `Explain OS process states.`
- **Output:** Long, generic paragraph.
- **Improved Prompt:** `List the 5 OS process states in 5 short bullet points.`
- **Output:** Clean, structured 5-point summary.
- **What Changed:** Adding exact count and bullet format made the output concise and scannable.

## Key Takeaway
Specific constraints and formatting instructions produce clearer AI responses.
